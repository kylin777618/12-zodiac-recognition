## 填写规则

1. **只从日志填**：每行对应 `results/logs/` 里的一个文件，文件名写进备注；
2. **测试集只评估一次**：训练过程中不许看测试集，最终三个模型各跑一次；
3. **失败也要留**：训崩的组合单独放"失败实验"小节，报告"五.3"要引用；
4. **同步导 CSV**：`python -m src.evaluate --export results/模型对比.csv`（E 实现后可用）。
