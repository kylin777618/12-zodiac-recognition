## 一、定死的参数

| 项目 | 口径 | 维护人 |
| --- | --- | --- |
| 类别顺序 | rat, ox, tiger, rabbit, dragon, snake, horse, goat, monkey, rooster, dog, pig（= `configs/base.yaml` 里 classes 的顺序，id 0–11） | 组长 |
| 样本量 | 每类 125 张，总数 1500 张 | B |
| 划分 | 分层抽样 8:1:1 = 训练 1200 / 验证 150 / 测试 150，`seed=42`，以 `data/split.json` 为准 | B |
| 输入尺寸 | 224×224，RGB，ImageNet 均值方差归一化 | B |
| 增强 | 随机水平翻转、±15° 旋转、色彩抖动、随机裁剪；**只作用于训练集** | B |
| 模型 | ① `baseline_cnn` ② `vgg16` ③ `resnet50`，输出层固定 12 个神经元，不加 Softmax | C / D |
| 训练 | 30 epoch，batch 32，早停 patience=5，按**验证集**挑最优权重 | C |
| 调参 | 12 组：lr{1e-3, 3e-4, 1e-4} × opt{sgd, adam} × act{relu, leaky_relu} | D |
| 指标 | Accuracy + macro Precision / Recall / F1 + 12×12 混淆矩阵；测试集**只评估一次** | E |
| 随机性 | 所有入口先 `set_seed(42)`（`src/config.py` + 各脚本开头），保证重跑一致 | 全员 |
| 演示 | 上传图片 → Top-1 + 置信度 + Top-3；权重本地加载，断网可跑 | F |

| 对象 | 格式 | 例子 |
| --- | --- | --- |
| 权重 | `models/{model}_best.pth`，调参中为 `{model}_lr{..}_{opt}_ep{..}.pth` | `vgg16_best.pth` |

| 分支 | `feat/{成员}-{模块}`，如 `feat/b-data-split` | — |
| 提交 | `[{成员}] 动词 + 对象`，如 `[B] 完成1500张数据清洗与划分` | — |
| 报告 | `AI报告-8点班-XX组-12生肖识别.pdf` | — |

## 三、不允许的三件事

1. **自己重新划分数据**：必须读 `data/split.json`。各划各的，测试集就泄漏了。
2. **用测试集调参**：选模型只许看验证集；测试集只在最终评估时开一次。
3. **手改 Excel 里的数字**：所有数字从 `results/logs/` 导出，改数据等于伪造实验结果。

## 四、变更流程

1. 在 Issue 里说明"为什么改、影响谁"；
2. 组长确认后改 `configs/base.yaml` 与本文档；
3. 提交信息写 `chore(config): ...`；
4. 改了类别顺序或划分的，必须通知 C/D/E 重跑。
