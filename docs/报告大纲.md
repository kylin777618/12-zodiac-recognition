## 写作纪律

1. **先出图再写字**：没有图支撑的结论不要写；
2. **每个数字带来源**："92.31%（表 2，vgg16）"，不要孤零零一个数；
3. **术语统一**：全篇用"准确率（Accuracy）"，不要一会儿"精度"一会儿"正确率"；
4. **失败要写**：无效尝试单独一段，这是评分标准里明确区分"真做过"的地方。
