```json

  "seed": 42,
  "classes": ["rat", "ox", "..."],
  "train": [{"path": "train/rat/0001.jpg", "label": 0}],
  "val":   [{"path": "val/rat/0001.jpg", "label": 0}],
```

## 采集与合规（B 在报告“四.2 数据方案”里要写清）

1. 来源清单：每条来源记录 URL、抓取日期、许可说明；
2. 去重：感知哈希（pHash）阈值 6，重复图只留一张；
3. 清洗标准：剔除多主体、明显卡通/插画混入、带大面积水印、分辨率 < 128px；
4. 人工抽检 100 张，抽检记录写在 `data/qa_sample.csv`；
5. 只用于课程作业，不再分发原始图片。
